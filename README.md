## Deployment

### Podman Compose

```yaml
services:
  nginx-base:
    image: "ghcr.io/daemonless/nginx-base:latest"
    container_name: nginx-base
    restart: unless-stopped
```

**.env**:

# .env

      - container: 'boot args:--pull'
